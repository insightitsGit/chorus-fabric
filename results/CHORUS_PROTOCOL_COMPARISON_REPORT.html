1. What Is CHORUS

CHORUS is a novel AI machine-to-machine (M2M) communication protocol that bypasses text tokenization entirely. Instead of serializing AI state into text, making HTTP/REST API calls, and having the receiving AI re-parse that text, CHORUS streams raw high-dimensional float32 tensor vectors directly over bidirectional gRPC streams.

Core Innovation

AI models communicate in embedding space, not token space. The same internal representation an LLM uses to reason — a vector of floats — is transmitted directly, with cryptographic security and authenticated delivery, without ever being converted to human language.

Key Finding — Cipher Overhead Is Zero

Direct mode p50 = 179 ms. The transatlantic speed-of-light round trip (8,000 km fiber) is ~165–180 ms. The tensor multiplication cipher (V_enc = V_raw @ K) and rolling SHA-256 watermark injection add zero measurable latency on top of raw network physics. The cryptographic security layer is essentially free.

Superposition Overhead Explanation

Superposition (Mode B) p50 = 1,274 ms vs 179 ms for Direct. This 7× overhead is entirely the holographic vector blend (V_A + V_B) and dual watermark injection running on a 1-vCPU Azure Container Instance. On GPU-backed infrastructure the same math runs in under 1 ms. This is a hardware constraint of the test environment, not a protocol limitation.

The Real Advantage Is Not Just Bytes — It's Latency + Semantics

At 1 billion signals/day, CHORUS saves ~$13.55/day vs LLM API on network egress alone. But the deeper advantage is that an LLM API call adds 1–3 seconds of model inference time on top of the same transatlantic network latency. For real-time AI coordination — high-frequency trading, multi-robot systems, distributed reasoning — CHORUS at 179 ms p50 operates in a fundamentally different performance class. The LLM API approach is not just slower; it becomes architecturally impossible for latency-sensitive applications.
